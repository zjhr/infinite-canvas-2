# 待测试

## 画布滚轮 / 触控板平移

- 画布支持鼠标滚轮与 Mac 触控板双指滑动平移画布（上下左右），`Shift + 滚轮` 横向移动；`Ctrl/⌘ + 滚轮`（触控板捏合）仍为以指针为中心缩放。
- 滚轮/触控板手势按帧合并（rAF 内一次性应用）：高频触控板事件不再逐个触发整页重渲染，平移抖动修复。
- 缩放系数重调：触控板捏合缩放速度约为原来的 10 倍以上，鼠标滚轮每格 1.1x → 1.49x。
- 节点内部可滚动区域（长文本、插件面板等）滚轮行为不变，仍优先滚动内容本身。

## 画布分组（成组 / 解组）

- `Ctrl/⌘ + G` 改为切换：未成组时把选中节点包成组，选中组框或组成员时解组（对齐旧项目）。
- 组节点悬浮工具栏新增「解组」按钮；右键菜单新增「成组 / 解组」项（按当前选择显示）；多选可成组节点时底部工具栏显示「成组」按钮。
- 右键节点时会先选中该节点再打开菜单（对齐旧项目），多选状态下右键已选节点保留多选。
- 解组会移除组框、释放成员归属并自动清掉空组，成员恢复为选中状态；撤销/重做可用。
- 已验证：框选成组、Cmd+G 双向切换、悬浮工具栏与右键菜单解组、拖拽节点进组吸附、撤销。

## 发送按钮重发送选择（新节点 / 替换）

- 已生成内容的图片/视频节点，提示词面板发送按钮变为分体式：主按钮生成到新节点，旁边下拉可选「新节点（保留当前结果，在旁边生成新节点）」或「替换此节点（覆盖此节点，沿用其原始参考）」，对齐旧项目。
- 替换此节点：图片节点沿用其生成时的原始参考（`metadata.references`，参考丢失时提示且不生成），结果原地写回当前节点（不新建节点、位置尺寸不变）；视频节点沿用当前上游参考原地写回。
- 已验证（本地假 OpenAI 图片端点 E2E）：图片替换原地更新、节点数不变；主按钮/新节点路径在旁边新建节点；视频替换走原地写回链路（假端点无视频接口返回 404，链路本身生效）。

## 视频节点截图按钮

- 视频节点播放按钮旁新增「截取当前帧」按钮：点击即把视频当前画面截成图片节点，自动连线到视频节点并选中，与右键菜单「截取当前帧」行为一致；进度条相应右移避让。
- 已验证：点击截图按钮生成图片节点并连线成功。

## Bug 修复

- 视频节点在画布无法拖动：video 元素触发浏览器原生拖拽（dragstart）劫持指针，补 `draggable={false}` 与 `onDragStart` 拦截（与图片节点 img 一致），拖动恢复正常；播放/暂停、截帧、进度条等控件行为不变。

## 节点插件系统（插件模式）

- 移植旧项目画布节点插件机制：底部工具栏新增「节点插件」入口，管理器支持官方插件注册表一键安装、本地插件（`web/public/plugins/`）开关、第三方 JS URL 安装/更新/卸载；插件产物与旧版生态同构（`globalThis.InfiniteCanvasRuntime` 宿主单例 React）。
- 插件节点可创建、连线、拖拽、缩放、删除；hover 工具条支持插件自定义按钮与「交互 ⇄ 移动」开关；节点下方面板、创建菜单、小地图颜色、作为上游资源被生成引用（`resource` 声明）均已接入。
- 插件可用能力：`ctx.applyOps` 画布指令集（增删节点/连线、选择、视口、触发生成）、插件私有 localforage 存储、事件总线、宿主 AI 生成（生图/生视频/生文本，复用当前渠道配置）。
- 修复插件 SDK 的 JSX 运行时：`jsx`/`jsxs` 改为转发宿主真实 jsx-runtime（此前退化成 `createElement`，静态多子元素会误报「unique key prop」控制台告警）；便利贴插件随仓库内置为本地插件 v1.1.1（含该修复），已安装的官方便利贴记录会在下次刷新时自动被本地修复版接管。
- 「添加节点」与「引用该节点生成」菜单增加视口感知的最大高度和内部滚动（按画布缩放换算），插件节点较多时菜单不再超出屏幕。

## 视频拼接节点（帧级剪辑）

- 官方插件「视频拼接」（video-concat v2.0）随仓库内置在 `web/public/plugins/`，在节点插件管理器启用后即可使用：收集画布视频、拖拽排序、首尾拼接输出 mp4/webm，结果本地持久化。
- 新增帧级修剪台：每段视频可展开胶片条，入/出点手柄拖拽、逐帧步进（1/30s）、播放头逐帧预览、`←`/`→` 逐帧（Shift ×10）、`I`/`O` 设入/出点，时间码精确到帧；裁剪覆盖整段时自动视为未裁剪。
- 拼接录制优化：录制器延后到首段就绪才启动、段间切换用 `pause/resume` 排除准备时间、段结束用媒体事件判定，成片时长与裁剪后总时长基本一致（实测误差约 0.1-0.2s）。
- 剪辑源统一经宿主媒体代理（`/api/proxy-image`）转成同源 blob URL：跨域生成视频（如 Agnes 输出，无 CORS 头）不再污染画布，缩略图「加载帧…」卡死与拼接失败修复；时长优先取源文件真实元数据（探测结果），不再显示生成接口返回的错误时长。
- 上传视频节点现在会写入时长元数据（`readVideoMeta` 补充 `durationMs`）；插件面板对缺时长的旧节点会自行探测兜底。

## 渠道孤儿脚本清理

- 渠道模型列表变化（删除模型）时，该模型挂载的自定义脚本同步清除；配置归一化时也会过滤已不存在模型的脚本，「脚本」按钮计数不再残留孤儿条目。

## 自定义模型脚本（视频）

- 本地渠道新增「脚本」入口：配置弹窗的每个本地渠道行增加「脚本」按钮，可给渠道内指定模型挂载自定义 JS 调用脚本，脚本完全接管该模型的视频生成请求（创建 + 轮询都由脚本完成）。
- 脚本契约：以 async 函数体运行，可用变量包括 `prompt`、`images`（参考图 dataURL 数组，下标 0 为首帧、1 为尾帧）、`videos` / `audios`（File 数组）、`params`（`{ mode, seconds, ratio, resolution, generateAudio, watermark }`）、`model`、`baseUrl`、`apiKey`、`http`（自动带 Bearer 和 baseUrl 拼 /v1）、`request`（原始请求）、`poll`（轮询，extract 返回真值即结束）、`sleep`、`signal`；返回 `{ url }` / `{ video_url }` / `{ result_url }`、`{ blob }` 或视频 URL 字符串。
- 编辑器提供变量说明（点击插入）、两个示例模板（OpenAI 兼容表单轮询、JSON 异步任务如 Agnes）和「复制代写提示词」（可粘贴给 AI 生成脚本）。
- 生效范围：本地渠道模式下按模型生效，云端渠道模式不生效；脚本返回的 Blob 会自动上传服务端对象存储换取稳定 URL。
- 已验证：挂载返回固定测试视频 URL 的脚本后，视频创作台生成直接得到该视频并正常展示；失败时错误信息正常显示在结果卡片。
